# Feedback

Drop a screenshot in `inbox/`. Name it whatever you like. Say "check the feedback folder".

That is the whole convention. There are no rules about filenames, no workflow ids to look up, and no file you have to edit. A screenshot called `IMG_4471.png` means "look at this" and I will ask what I need to know.

If you want to write more than a filename holds, put any `.md` file in `inbox/` and write freely. No format.

## What I do with it

Read everything in `inbox/`, act on it, then move the files to `processed/` so the inbox only ever holds what I have not seen. You never touch `processed/`.

## What is committed

Screenshots stay on your machine, gitignored. Any `.md` notes are committed, so the words survive in history and the pixels do not bloat it. If a particular screenshot is worth keeping as evidence, say so and I will commit that one deliberately.
